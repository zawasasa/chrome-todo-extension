# ささっとeverytodo - Chrome拡張機能

平日のルーティンワークと日常のタスクを効率的に管理するChrome拡張機能です。

## ✨ 主な機能

### 📱 基本機能
- **サイドパネル表示**: Chromeのサイドパネルでタスクを管理
- **レスポンシブデザイン**: サイドパネルの幅に応じて自動調整
- **リアルタイム更新**: 進捗状況をリアルタイムで表示
- **パッションオレンジUI**: 見やすいグラデーションデザイン

### 📋 タスク種別
- **毎日（平日のみ）**: 月曜日〜金曜日に実行されるルーティンタスク
- **毎週**: 指定した曜日のみ実行（複数曜日選択可能）
- **毎月**: 指定した日付で実行（月末日の指定も可能）
- **今日だけのToDo**: その日限りの単発タスク（土日も利用可能）
- **延期タスク**: 未完了タスクの翌日送り機能

### 📅 カレンダー機能
- **ミニカレンダー**: 月単位でタスクを俯瞰
- **未来のタスク追加**: カレンダーから直接未来の日付にタスク追加
- **タスク表示**: 各日付にタスクの有無を視覚的に表示
- **日付プレビュー**: 選択した日のタスク一覧を表示

### ⏰ タスク管理
- **進捗表示**: 完了/全体タスク数の表示
- **延期機能**: 17時以降に未完了タスクの延期選択
- **元日付表示**: 延期されたタスクの元の予定日を表示
- **削除機能**: 今日だけのタスクと延期タスクの削除

### 📊 活動ログ
- **操作履歴**: すべてのタスク操作を時系列で記録
- **詳細ログ**: 追加・完了・削除・延期の各アクションを記録
- **時刻表示**: 「今日 14:30」「昨日」「3日前」などの分かりやすい形式
- **設定画面で確認**: 過去の活動を一覧で確認可能

## 🚀 インストール方法

1. **開発者モードを有効化**
   - Chromeの設定 → 拡張機能 → 「開発者モード」をON
2. **拡張機能を読み込み**
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - このフォルダを選択してインストール
3. **サイドパネルを有効化**
   - 拡張機能アイコンをクリックするとサイドパネルが表示されます

## 📖 詳細な使用方法

### 🔧 初期設定（最初の1回のみ）

1. **拡張機能のインストール後**
   - Chromeツールバーの拡張機能アイコン（チェックボックス+「さ」のデザイン）をクリック
   - サイドパネルが右側に表示されます

2. **ルーティンタスクの登録**
   - 「設定」ボタンをクリックして設定画面を開く
   - 「新しいタスクを追加」セクションで以下を入力：
     - **タスク名**: 例）「メールチェック」「日報作成」「朝の体操」
     - **実行頻度**: 毎日（月〜金）/ 毎週（指定曜日）/ 毎月（指定日）を選択
     - **詳細設定**:
       - 毎週の場合：月火水木金の中から実行する曜日をチェック
       - 毎月の場合：1〜31日または「月末」を選択
   - 「追加」ボタンでタスクを保存

3. **登録したタスクの確認**
   - 設定画面下部の「登録済みタスク」で一覧表示
   - 編集ボタンで内容変更、削除ボタンで削除可能

### 📅 日常の使用方法

#### メイン画面（タスク管理）
1. **今日のタスク確認**
   - 拡張機能アイコンをクリックしてサイドパネルを開く
   - 今日実行すべきルーティンタスクが自動表示
   - 右上に「3/5 完了」のような進捗が表示

2. **タスクの完了**
   - 各タスクの左側チェックボックスをクリック
   - 完了したタスクは取り消し線で表示され、下に移動
   - チェックを外すと未完了状態に戻る

3. **今日だけのタスク追加**
   - 「今日だけのToDo」セクションの入力欄にタスク名を入力
   - 「追加」ボタンまたはEnterキーで追加
   - 例）「銀行に行く」「プレゼントを買う」など単発のタスク
   - 土日でも利用可能（ルーティンタスクは平日のみ）

#### カレンダー機能
1. **カレンダー表示**
   - 📅ボタンをクリックしてカレンダービューに切り替え
   - 現在の月のカレンダーが表示され、タスクがある日には小さな赤い点が表示

2. **未来のタスク追加**
   - カレンダーで日付をクリックして選択
   - 選択した日が今日以降の場合、下部に入力欄が表示
   - タスク名を入力して「追加」ボタンでその日のタスクとして登録

3. **日付別タスク確認**
   - カレンダーで任意の日付をクリック
   - 下部にその日のタスク一覧が表示（ルーティン+今日だけ+延期）
   - 未来や過去の日付のタスクも確認可能

4. **フォームからの未来タスク追加**
   - メイン画面の「未来のやること」セクションを使用
   - タスク名と実行日を指定して「追加」ボタン
   - カレンダー表示時に指定日に反映される

#### 延期機能（17時以降の便利機能）
1. **自動表示**
   - 17時以降にサイドパネルを開くと、未完了タスクがある場合に延期セクションが表示
   - 「未完了のタスク」という黄色いセクションが画面下部に出現

2. **延期の実行**
   - 「全て明日に送る」ボタン：未完了のタスクを翌日（平日なら翌平日）に移動
   - 「今日は完了」ボタン：延期せずに今日を完了扱いにする

3. **延期されたタスクの表示**
   - 延期されたタスクは翌日「延期」タグで表示
   - 元の予定日が表示される（例：「(9/25)」「昨日から」「3日前から」）

### 📊 活動ログの確認

1. **ログへのアクセス**
   - 「設定」ボタンをクリックして設定画面を開く
   - 画面を下にスクロールして「活動ログ」セクションを確認

2. **ログの内容**
   - **タスクを追加**: 新しいタスクを作成した記録
   - **タスクを完了**: チェックボックスをONにした記録
   - **タスクを削除**: ×ボタンで削除した記録
   - **タスクを延期**: 翌日に送った記録

3. **時刻表示の見方**
   - 今日の操作：「14:30」（時:分）
   - 昨日の操作：「昨日 09:15」
   - それ以前：「3日前」「9/23」

### 🔄 その他の便利機能

#### 更新ボタン
- 画面の表示がおかしくなった時や、日付が変わった後に手動更新
- 通常は1分ごとに自動更新されるため、手動更新は稀に使用

#### 削除機能
- 「今日だけのToDo」と「延期されたタスク」のみ削除可能
- 各タスクの右端にある「×」ボタンをクリック
- ルーティンタスクは設定画面からのみ削除可能

#### レスポンシブ対応
- サイドパネルの幅を変更すると、自動的にレイアウトが調整
- 狭い幅でも使いやすいように最適化

### 💡 使用のコツ

1. **朝のルーティン**: 出社後にサイドパネルを開いて今日のタスクを確認
2. **随時更新**: タスク完了の都度チェックボックスをクリックして進捗を実感
3. **夕方の整理**: 17時以降に延期機能を使って翌日の準備
4. **週末の準備**: 金曜日に来週のタスクをカレンダーで確認・追加
5. **振り返り**: 月末に活動ログで1ヶ月の作業パターンを確認

## 🔧 技術仕様

- **Manifest Version**: 3
- **権限**: `storage`, `sidePanel`
- **ストレージ**: Chrome Local Storage API
- **UI フレームワーク**: Vanilla JavaScript
- **デザイン**: レスポンシブCSS（複数ブレークポイント対応）
- **対応ブラウザ**: Chrome 114+ (Manifest V3対応版)

## ⚠️ 制約事項

- **時刻指定**: 具体的な時刻指定機能はなし（17時以降の延期判定のみ）
- **同期機能**: シングルユーザー対応（複数デバイス間同期なし）
- **オフライン**: 完全オフライン動作（外部API不使用）
- **ルーティンタスク**: 平日（月〜金）のみ表示（土日は今日だけのToDoのみ）
