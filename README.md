# タスク管理 Chrome拡張機能

日々のルーティンワークを効率的に管理するChrome拡張機能です。

## 機能

### 基本機能
- **サイドパネル表示**: Chromeのサイドパネルでタスクを管理
- **毎日利用可能**: 平日・休日問わず毎日利用可能
- **タスク完了管理**: チェックボックスで完了状態を管理
- **自動リセット**: 翌日に完了状態が自動リセット

### タスク種別
- **毎日**: 毎日実行
- **毎週**: 指定した曜日のみ実行（土日含む）
- **毎月**: 指定した日付で実行（月末も対応）

### 設定機能
- タスクの追加・編集・削除
- 実行頻度の設定
- 曜日・日付の詳細設定

## インストール方法

1. Chrome拡張機能の開発者モードを有効にする
2. 「パッケージ化されていない拡張機能を読み込む」をクリック
3. このフォルダを選択してインストール

## 使用方法

1. Chrome拡張機能アイコンをクリックしてサイドパネルを開く
2. 初回は「設定」ボタンからタスクを追加
3. サイドパネルを開いてタスクをチェック
4. 完了したタスクは取り消し線で表示される

## ファイル構成

```
├── manifest.json          # 拡張機能の設定
├── background.js          # バックグラウンドスクリプト
├── sidepanel.html         # メインパネルのHTML
├── sidepanel.js           # メインパネルのJavaScript
├── sidepanel.css          # メインパネルのスタイル
├── settings.html          # 設定画面のHTML
├── settings.js            # 設定画面のJavaScript
├── settings.css           # 設定画面のスタイル
├── icons/                 # アイコンファイル
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md              # このファイル
```

## 技術仕様

- **Manifest Version**: 3
- **権限**: storage, sidePanel
- **ストレージ**: Chrome Local Storage
- **対応ブラウザ**: Chrome (Manifest V3対応版)

## 制約事項

- 時刻指定機能なし
- シングルユーザー対応（同期機能なし）
- オフライン動作
